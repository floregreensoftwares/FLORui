Obtained via the `cosmic-text` crate's bundled test fonts (also OFL-licensed, same file), not modified.

Kept as the crate's monospace family: a fixed advance width per glyph lets measurement tests assert exact expected values instead of tolerating font-specific shaping quirks.

`OpenSans-Variable.ttf` is the variable-font build of [Open Sans](https://github.com/googlefonts/opensans) (The Open Sans Project Authors), licensed under the SIL Open Font License 1.1 — see `OpenSans-LICENSE` in this directory. Obtained from the [`google/fonts`](https://github.com/google/fonts/tree/main/ofl/opensans) repository (`ofl/opensans/OpenSans[wdth,wght].ttf`), not modified. Used at its default (regular weight/width) instance — this crate does not vary either axis.

This crate's sans-serif default, standing in for what a browser would typically show when nothing more specific is requested. Explicitly *not* metrically matched to Arial (Liberation Sans/Arimo exist for that purpose and were the other candidate) — chosen instead for being a widely used, actively maintained open family in its own right. A stylesheet that specifically needs Arial-compatible line-wrapping will measure differently than it would in a real browser; this is a deliberate scope limit, not an oversight.

`OpenSans-Italic-Variable.ttf` is the italic of the same family, the variable-font build `OpenSans-Italic[wdth,wght].ttf` from the same [`google/fonts`](https://github.com/google/fonts/tree/main/ofl/opensans) directory, under the same license (`OpenSans-LICENSE`), not modified. It is what `font-style: italic` and `oblique` draw in sans-serif. Fira Mono has no italic, so an italic in monospace is the upright face leaned by hand, as a browser does for a family with none.
